## 1. 인증 기능

### FN-AUTH-001. Google 로그인
| 항목 | 내용 |
|------|------|
| 설명 | Firebase Auth를 통한 Google OAuth 로그인 |
| 트리거 | 로그인 화면에서 "구글 계정으로 로그인" 버튼 클릭 |
| 동작 | Google 팝업 인증 -> Firebase Auth 토큰 발급 -> Firestore 연동 |
| 결과 | 메인 대시보드로 이동, 프로필 아이콘 표시 |
| 오류 표시 | 승인 도메인 누락, 팝업 닫힘, 팝업 차단 등 주요 실패 사유를 화면에 표시 |

### FN-AUTH-002. 비로그인 (게스트 모드)
| 항목 | 내용 |
|------|------|
| 설명 | 계정 없이 로컬 데이터만으로 사용 |
| 트리거 | "비로그인으로 계속하기" 버튼 클릭 |
| 동작 | localStorage에 `mobimobi_guest` 플래그 설정 |
| 결과 | 메인 대시보드 이동, 헤더에 내보내기/가져오기/설정 아이콘 표시 |
| 제한 | 브라우저 한정, 쿠키 삭제 시 데이터 유실 가능 |

### FN-AUTH-003. 로그아웃
| 항목 | 내용 |
|------|------|
| 설명 | 현재 세션 종료 및 로그인 화면으로 복귀 |
| 트리거 | 설정(ProfileModal) > "로그인 화면으로" 버튼 클릭 |
| 동작 | 경고 모달 표시 -> 확인 시 localStorage 클리어 + Firebase signOut |
| 주의 | 로그아웃 전 데이터 백업 권장 안내 (경고 모달) |

### FN-AUTH-004. 계정 삭제
| 항목 | 내용 |
|------|------|
| 설명 | Firebase 계정 및 관련 데이터 영구 삭제 |
| 트리거 | 설정 > 계정 삭제 버튼 |
| 동작 | Firestore 데이터 삭제 + Firebase Auth 계정 삭제 |
| 비가역 | 복구 불가 |

## 2. 캐릭터 관리

### FN-CHAR-001. 캐릭터 생성
| 항목 | 내용 |
|------|------|
| 설명 | 새 캐릭터 등록 |
| 트리거 | 캐릭터 탭의 "+" 버튼 클릭 |
| 입력 | 서버, 캐릭터명, 메인 클래스 계열, 세부 직업 |
| 제한 | 서버당 최대 6캐릭터 |
| 동작 | 캐릭터 생성 + 현재 리스트 템플릿 복사. 현재 리스트가 비어 있으면 빈 리스트로 생성 |

### FN-CHAR-002. 캐릭터 수정
| 항목 | 내용 |
|------|------|
| 설명 | 기존 캐릭터 정보 편집 |
| 트리거 | 캐릭터 탭에서 캐릭터 길게 누르기 또는 편집 버튼 |
| 수정 가능 | 서버, 캐릭터명, 메인 클래스, 세부 직업 |

### FN-CHAR-003. 캐릭터 삭제
| 항목 | 내용 |
|------|------|
| 설명 | 캐릭터 및 연관 데이터 삭제 |
| 트리거 | 캐릭터 편집 모달에서 삭제 버튼 |
| 동작 | 캐릭터 + 해당 캐릭터의 모든 숙제/구매/물물교환/임무게시판 데이터 삭제 |

### FN-CHAR-004. 캐릭터 순서 변경
| 항목 | 내용 |
|------|------|
| 설명 | 캐릭터 탭 순서 드래그앤드롭으로 변경 |
| 범위 | 같은 서버 내 캐릭터 간 순서 변경 |

## 3. 숙제 관리 (일일/주간)

### FN-HW-001. 숙제 체크
| 항목 | 내용 |
|------|------|
| 설명 | 숙제 완료 상태 토글 |
| 동작 | 체크박스 클릭 시 completedCount 증가/감소 |
| 다중 체크박스 | totalCount에 따라 1~10개 체크박스 표시 |
| 완료 판정 | completedCount >= totalCount |

### FN-HW-002. 숙제 추가
| 항목 | 내용 |
|------|------|
| 설명 | 새로운 숙제 카드 생성 |
| 트리거 | "숙제 추가" 버튼 -> AddCardModal에서 "일일 숙제" 또는 "주간 숙제" 선택 |
| 입력 | 숙제 이름, 보상(선택), 체크박스 수, 범위(캐릭터/서버) |
| 동기화 | **모든 캐릭터에 동일하게 추가** |

### FN-HW-003. 숙제 수정
| 항목 | 내용 |
|------|------|
| 설명 | 기존 숙제 카드 내용 편집 |
| 트리거 | 카드의 연필 아이콘 클릭 |
| 수정 가능 | 숙제 이름, 보상, 체크박스 수, 범위(캐릭터/서버) |
| 동기화 | **모든 캐릭터에 동일하게 반영** (인덱스 기반) |

### FN-HW-004. 숙제 삭제
| 항목 | 내용 |
|------|------|
| 설명 | 숙제 카드 삭제 |
| 트리거 | 카드의 쓰레기통 아이콘 -> 확인 모달 |
| 동기화 | **모든 캐릭터에서 동일 위치 카드 삭제** |

### FN-HW-005. 숙제 순서 변경
| 항목 | 내용 |
|------|------|
| 설명 | 드래그앤드롭으로 카드 순서 변경 |
| 동기화 | **모든 캐릭터에 동일하게 반영** |

### FN-HW-006. 숙제 즐겨찾기
| 항목 | 내용 |
|------|------|
| 설명 | 별표(★) 토글로 즐겨찾기 설정/해제 |
| 범위 | **캐릭터별 독립 적용** (다른 캐릭터에 영향 없음) |
| 필터 | 즐겨찾기 필터 활성화 시 ★ 항목만 표시 |

## 7. 프리셋 관리

### FN-PRE-001. 기본 프리셋
| 항목 | 내용 |
|------|------|
| 이름 | "기본 숙제 설정" |
| ID | `__default__` |
| 포함 | 기본 숙제 + 기본 구매 + 기본 물물교환 + 기본 임무게시판 |
| 삭제 | 불가 |

### FN-PRE-002. 프리셋 저장
| 항목 | 내용 |
|------|------|
| 설명 | 현재 캐릭터의 숙제/구매/물물교환/임무게시판 구성을 프리셋으로 저장 |
| 트리거 | 숙제 설정 > `현재 리스트 저장` |
| 저장 항목 | 카드 이름, 보상, 주기, 범위, 체크박스 수 등 |
| 제외 항목 | **즐겨찾기(isFavorite)**, completedCount, completed, id |

### FN-PRE-003. 프리셋 불러오기
| 항목 | 내용 |
|------|------|
| 설명 | 저장된 프리셋을 카드 리스트 템플릿으로 적용 |
| 트리거 | 숙제 설정 > `저장한 리스트` |
| 동작 | 등록된 캐릭터들의 숙제/구매/물물교환/임무게시판 전체 교체 |
| 상태 보존 | 동일 카드 매칭 시 기존 체크 상태와 즐겨찾기를 `savedItemStates` 기준으로 최대한 복원 |

### FN-PRE-004. 프리셋 삭제
| 제한 | 기본 프리셋(`__default__`)은 삭제 불가 |

### FN-PRE-005. 백업/복원
| 항목 | 내용 |
|------|------|
| 트리거 | 숙제 설정 > `백업/복원` |
| UI | 모달 안에 `백업 파일 저장`, `백업 파일 가져오기`, `닫기` 버튼 표시 |
| 내보내기 | 현재 캐릭터 구성을 JSON 파일로 다운로드 |
| 가져오기 | JSON 파일을 업로드하여 현재 캐릭터에 적용 |
| 보존 | 가져오기 전후 기존 캐릭터의 체크 상태와 즐겨찾기를 가능한 범위에서 보존 |

### FN-PRE-006. 빈 리스트로 시작
| 항목 | 내용 |
|------|------|
| 설명 | 기본 카드 없이 빈 리스트에서 사용자가 직접 카드 구성을 만들 수 있음 |
| 트리거 | 숙제 설정 > `빈 리스트로 시작` |
| 기존 카드 있음 | `저장 후 새로 만들기 / 저장하지 않고 새로 만들기 / 취소` 모달 표시 |
| 기존 카드 없음 | 즉시 빈 리스트 상태 유지 |
| 동작 | 등록된 캐릭터들의 숙제/구매/물물교환/임무게시판 리스트를 빈 배열로 초기화 |

### FN-PRE-007. 기본 숙제 설정 불러오기
| 항목 | 내용 |
|------|------|
| 설명 | 빈 리스트 상태에서 관리자 기본 카드 리스트를 불러옴 |
| 트리거 | 빈 상태 화면의 `기본 숙제 설정 불러오기` 버튼 |
| 기준 데이터 | Firestore published 기본 카드, 없으면 코드 기본값 |
| 동작 | 등록된 캐릭터들의 기본 카드 리스트를 생성 |

## 8. 데이터 관리

### FN-DATA-001. 전체 데이터 내보내기
| 항목 | 내용 |
|------|------|
| 설명 | 전체 계정 데이터를 JSON 파일로 다운로드 |
| 트리거 | 헤더의 Download 아이콘 클릭 (게스트 모드) |
| 파일명 | `mobi-account-data-YYYY-MM-DD.json` |

### FN-DATA-002. 전체 데이터 가져오기
| 항목 | 내용 |
|------|------|
| 설명 | JSON 파일을 업로드하여 전체 데이터 복원 |
| 트리거 | 헤더의 Upload 아이콘 클릭 (게스트 모드) |
| 동작 | 확인 모달 표시 -> 승인 시 현재 데이터 덮어쓰기 + 페이지 새로고침 |
| 검증 | characters, homework 필드 존재 여부 확인 |

### FN-DATA-003. 체크박스 전체 해제
| 항목 | 내용 |
|------|------|
| 설명 | 현재 카드 리스트의 체크 상태를 전체 해제 |
| 트리거 | 전체 진행도 > `체크 초기화` 버튼 |
| 주의 | 카드 구성 자체를 기본값으로 되돌리는 기능이 아님 |

## 9. 리셋 시스템

### FN-RESET-001. 일간 리셋
| 항목 | 내용 |
|------|------|
| 시각 | 매일 오전 06:00 KST (= UTC 전날 21:00) |
| 대상 | period="daily"인 모든 항목 |
| 숙제 | completedCount -> 0 |
| 구매/물물교환 | completed -> false |
| 임무게시판 | completedCount -> 0 |
| 기록 | lastDailyReset 갱신 |

### FN-RESET-002. 주간 리셋

### 12.2 HomeworkItem
```typescript
interface HomeworkItem {
  id: string;              // "{charId}_hw_{index}"
  title: string;           // 숙제 이름
  reward: string;          // 보상 정보
  period: PeriodType;      // "daily" | "weekly"
  totalCount: number;      // 체크박스 수 (1~10)
  completedCount: number;  // 완료 체크 수
  isFavorite: boolean;     // 즐겨찾기 (캐릭터별 독립)
  scope?: ScopeType;       // "character" | "server"
}
```

### 12.3 ShopItem (구매 / 물물교환)
```typescript
interface ShopItem {
  id: string;           // "{charId}_pur_{ts}" 또는 "{charId}_trd_{ts}"
  itemName: string;     // 아이템 이름
  region: RegionName;   // 지역 (8개 중 택 1)
  npcName: string;      // NPC 이름 (쉼표 구분 다중 태그)
  period: PeriodType;   // "daily" | "weekly"
  completed: boolean;   // 완료 여부
  isFavorite: boolean;  // 즐겨찾기 (캐릭터별 독립)
  scope?: ScopeType;    // "character" | "server"
}
```

### 12.4 ScrollItem (임무게시판)
```typescript
interface ScrollItem {
  id: string;              // "{charId}_scroll_{index}"
  title: string;           // 스크롤 이름
  scrollType: ScrollType;  // "제작" | "채집" | "요리" | "토벌"
  period: PeriodType;      // "daily" | "weekly"
  totalCount: number;      // 체크박스 수 (기본 3, 최대 10)
  completedCount: number;  // 완료 체크 수
  isFavorite: boolean;     // 즐겨찾기 (캐릭터별 독립)
  scope?: ScopeType;       // "character" | "server"
  region: RegionName;      // 지역
  materials: string[];     // 재료 목록 (토벌 시 숨김)
  reward: string;          // 보상 정보
  tags?: string[];         // 추가 태그 (예비)
}
```

```typescript
interface HomeworkPreset {
  id: string;

  tradeItems: Omit<ShopItem, "id" | "completed" | "isFavorite">[];

```

interface AppData {

  lastWeeklyReset: string;  // ISO 8601
  presets?: HomeworkPreset[];

}

### FN-ADMIN-006. Firestore 보안 규칙
| 항목 | 내용 |
|------|------|
| 사용자 데이터 | `users/{userId}`는 본인만 읽기/쓰기 가능 |
| published | 모든 사용자 읽기 가능, 관리자만 쓰기 가능 |
| draft/history | 관리자만 읽기/쓰기 가능 |
| 관리 방식 | `firestore.rules` 파일로 관리하며 Firebase Console 또는 Firebase CLI로 게시 |
