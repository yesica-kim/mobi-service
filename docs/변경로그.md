# 변경로그

이 파일은 이안(Yian OS) 또는 프로젝트 채팅에서 직접 수행한 변경사항을 기록하는 곳이야.

작은 수정이라도 다음 작업자가 맥락을 놓치지 않도록, 수정 파일과 검증 결과를 함께 남긴다.

## 2026-05-23

### 관리자 이메일 화이트리스트 판별 보강

- 작업 위치: 프로젝트 채팅
- 수정 파일:
  - `src/lib/adminFirestore.ts`
  - `src/app/page.tsx`
  - `src/app/ctrl-a7x9k2m/page.tsx`
- 변경 내용:
  - `NEXT_PUBLIC_ADMIN_EMAIL` 값 비교 시 앞뒤 공백과 따옴표를 제거하도록 보강.
  - 쉼표로 여러 관리자 이메일을 등록해도 동작하도록 처리.
  - Firebase `user.email`뿐 아니라 `providerData[].email`도 관리자 화이트리스트 판별에 사용.
- 배경:
  - 실섭 배포 후 화이트리스트 계정으로 로그인해도 관리자 아이콘이 보이지 않는 현상 대응.
  - Vercel 환경변수에 따옴표나 공백이 포함되어 저장된 경우에도 정상 판별되도록 수정.
  - Google 로그인 정보가 provider data에만 잡히는 경우에도 관리자 페이지 접근과 헤더 아이콘이 동작하도록 보강.
