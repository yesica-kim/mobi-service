# 변경로그

이 파일은 이안(Yian OS) 또는 프로젝트 채팅에서 직접 수행한 변경사항을 기록하는 곳이야.

작은 수정이라도 다음 작업자가 맥락을 놓치지 않도록, 수정 파일과 검증 결과를 함께 남긴다.

## 2026-05-26

### 캐릭터 전체 보기 컬러와 컬럼 정렬 보정

- 작업 위치: 프로젝트 채팅
- 수정 파일:
  - `src/app/page.tsx`
  - `src/components/HomeworkCard.tsx`
  - `src/components/ShopCard.tsx`
  - `src/components/ScrollCard.tsx`
  - `src/components/SearchFilterBar.tsx`
- 변경 내용:
  - 캐릭터 전체 보기의 항목 헤더를 세로 가운데 정렬.
  - 캐릭터 전체 보기 행 사이 구분선을 더 선명하게 조정.
  - 항목 컬럼과 캐릭터 컬럼 사이, 각 캐릭터 컬럼 사이에 세로 구분선 추가.
  - 캐릭터 전체 보기 체크 완료 컬러를 캐릭터별 카드의 타입별 완료 컬러와 맞춤.
  - 미완료 체크박스 배경을 두 보기에서 공통으로 `slate-900/70` 계열의 중간 톤으로 조정.
  - 캐릭터 전체 보기 컬럼 폭을 줄여 780px 기준 6개 캐릭터가 한 화면에 보이도록 조정.
  - 모바일 캐릭터 전체 보기 체크 칩에도 동일한 체크박스 컬러 기준 적용.
  - 카드 검색 인풋과 필터 버튼 높이를 48px로 통일하고 배경을 더 어둡게 조정.
- 배경:
  - 캐릭터 전체 보기와 캐릭터별 보기의 색상/완료 피드백/구분선 밀도를 맞추고, 6캐릭터 사용 시 가로 스크롤 부담을 줄이기 위한 조정.

### 카드 완료 컬러 및 즐겨찾기 진행도 정리

- 작업 위치: 프로젝트 채팅
- 수정 파일:
  - `src/app/page.tsx`
  - `src/hooks/useAppState.ts`
- 변경 내용:
  - 캐릭터 전체 보기의 PC/태블릿 표형과 모바일 카드형 배경을 캐릭터별 카드 배경과 동일하게 정렬.
  - 미완료 카드는 `bg-slate-800`, 완료 카드는 `bg-slate-800/40 opacity-50` 기준으로 표시.
  - 서버 범위 카드는 캐릭터 전체 보기에서 1개 캐릭터만 체크되어도 행/카드를 완료 배경으로 표시.
  - 캐릭터 범위 카드는 모든 캐릭터 셀이 완료되어야 행/카드를 완료 배경으로 표시.
  - 즐겨찾기 필터 상태의 진행도 총합을 체크박스 횟수가 아닌 즐겨찾기 카드 수 기준으로 계산하도록 수정.
  - 다회 체크 카드의 즐겨찾기 완료 수는 `completedCount`가 `totalCount`에 도달했을 때만 1개 완료로 계산.
- 배경:
  - PC 캐릭터별 보기, PC 캐릭터 전체 보기, 모바일 캐릭터 전체 보기 간 카드 배경 톤이 달라 보이는 문제 대응.
  - 즐겨찾기 진행도에서 카드 수와 체크 횟수가 섞여 총 개수가 과대 표시되는 문제 대응.
