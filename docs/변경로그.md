# 변경로그

이 파일은 이안(Yian OS) 또는 프로젝트 채팅에서 직접 수행한 변경사항을 기록하는 곳이야.

작은 수정이라도 다음 작업자가 맥락을 놓치지 않도록, 수정 파일과 검증 결과를 함께 남긴다.

## 2026-05-27

### v1.3.1 관리자 기본 카드 순서 반영 범위 보정

- 작업 위치: 프로젝트 채팅
- 수정 파일:
  - `src/lib/storage.ts`
- 변경 내용:
  - 관리자 페이지에서 기본 카드 순서를 변경해도 이미 사용 중인 사용자 리스트 순서가 앱 로드/동기화 시 자동 변경되지 않도록 수정.
