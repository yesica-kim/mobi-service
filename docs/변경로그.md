# 변경로그

이 파일은 이안(Yian OS) 또는 프로젝트 채팅에서 직접 수행한 변경사항을 기록하는 곳이야.

작은 수정이라도 다음 작업자가 맥락을 놓치지 않도록, 수정 파일과 검증 결과를 함께 남긴다.

### 캐릭터별/리스트별 보기 모드 추가

- 작업 위치: 프로젝트 채팅
- 수정 파일:
  - `src/app/page.tsx`
  - `src/hooks/useAppState.ts`
- 변경 내용:
  - 기존 캐릭터 중심 UI를 유지하면서 `캐릭터별` / `리스트별` 보기 탭 추가.
  - `리스트별` 보기에서 항목명 컬럼은 고정하고, 캐릭터 체크 컬럼은 가로 스크롤되는 매트릭스 UI 추가.
  - 리스트별 보기에서는 숙제/구매/물물교환/임무게시판 체크를 캐릭터별로 바로 토글 가능.
  - 다중 체크 항목은 셀 클릭 시 `0 -> 1 -> ... -> 완료 -> 0` 순서로 순환.
  - 서버 범위 구매/숙제는 기존 규칙처럼 같은 서버 캐릭터에 함께 반영.
- 배경:
  - 캐릭터를 먼저 선택하는 기존 흐름 외에, 항목 리스트를 기준으로 캐릭터별 완료 여부를 한 화면에서 확인하는 운영형 뷰가 필요해짐.
