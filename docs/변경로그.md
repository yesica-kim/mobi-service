# 변경로그

이 파일은 이안(Yian OS) 또는 프로젝트 채팅에서 직접 수행한 변경사항을 기록하는 곳이야.

작은 수정이라도 다음 작업자가 맥락을 놓치지 않도록, 수정 파일과 검증 결과를 함께 남긴다.

## 2026-05-23

- 작업 위치: 프로젝트 채팅
- 수정 파일:
  - `src/app/page.tsx`
  - `src/lib/adminFirestore.ts`
- 변경 내용:
  - 헤더 관리자 아이콘 노출 조건을 로그인 사용자 전체에서 `isAdmin` 승인 사용자로 복구.
  - Vercel 환경변수 오설정/누락 상황에서도 `inchu594@gmail.com`은 기본 승인 이메일로 포함되도록 보정.
- 배경:
  - 승인되지 않은 Google 계정에도 관리자 아이콘이 보이는 문제 수정.
  - 승인 계정 `inchu594@gmail.com`으로도 관리자 페이지 권한 확인이 실패하는 문제 수정.

### 관리자 진입 위치 설정 모달로 이동

### 전체 탭 통합 정렬 및 관리자 진입 보강

- 작업 위치: 프로젝트 채팅
- 수정 파일:
  - `src/app/page.tsx`
  - `src/hooks/useAppState.ts`
  - `src/types/index.ts`
  - `src/components/ProfileModal.tsx`
- 변경 내용:
  - `전체` 탭에서 일간/주간/구매/물물교환/임무게시판 카드를 하나의 리스트로 드래그 정렬할 수 있도록 변경.
  - 캐릭터별 `allTabOrder`를 저장해 전체 탭의 교차 타입 정렬 순서를 유지.
  - 헤더의 업데이트 노트 옆에 관리자 아이콘을 다시 배치.
  - 프로필 모달에는 앱이 인식한 이메일/provider 이메일만 표시하고 관리자 페이지 진입 버튼은 제거.
- 배경:
  - 전체 탭에서 카드 타입과 관계없이 순서 변경이 필요하다는 요청 반영.
  - 화이트리스트 계정 로그인 후에도 관리자 아이콘이 보이지 않는 현상 원인 확인 및 우회 진입 보강.

### 관리자 이메일 화이트리스트 판별 보강

- 작업 위치: 프로젝트 채팅
- 수정 파일:
  - `src/lib/adminFirestore.ts`
  - `src/app/page.tsx`
  - `src/app/ctrl-a7x9k2m/page.tsx`
- 변경 내용:
  - `NEXT_PUBLIC_ADMIN_EMAIL` 값 비교 시 앞뒤 공백과 따옴표를 제거하도록 보강.
  - 쉼표로 여러 관리자 이메일을 등록해도 동작하도록 처리.
  - Firebase `user.email`뿐 아니라 `providerData[].email`도 관리자 화이트리스트 판별에 사용.
- 배경:
  - 실섭 배포 후 화이트리스트 계정으로 로그인해도 관리자 아이콘이 보이지 않는 현상 대응.

  - Google 로그인 정보가 provider data에만 잡히는 경우에도 관리자 페이지 접근과 헤더 아이콘이 동작하도록 보강.
